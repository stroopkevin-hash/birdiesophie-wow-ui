# BirdieSophieUI

Birdie & Breakfast UI companion for World of Warcraft: The Burning Crusade Anniversary.

## Installation with WowUp

1. Open **Get Addons** in WowUp.
2. Choose **Install from URL**.
3. Paste this repository URL.
4. Import and install for the `_anniversary_` client.

The packaged release contains the `BirdieSophieUI` addon folder. ElvUI is required; WeakAuras and Details! are optional companions.

After logging in, use `/bsui status` to verify the installation.
